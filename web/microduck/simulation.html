What this demonstrates

This standalone page uses the reviewed JSON-RPC client with fragmented, in-memory replies. It does not connect to the Linux simulator, SmallVM, Bluetooth or any network endpoint. Starting or refreshing it never discovers a device.

Brief requirementCurrent boundary
Identity, Wi-Fi status, IP and batteryFictional API-shaped responses only. The demo network is open and needs no password. 192.0.2.44 is a documentation address.
Sounds and discovered skillsMock actions recorded in memory, limited to 32 per session. Each action needs a fresh confirmation.
Authentication and real Wi-Fi provisioningNo PIN or password inputs. Real Web Bluetooth secret transmission remains blocked because link confidentiality is unverified.
Installation, updates, rollback and continuous controlUnavailable in this demo. No commands, software changes, movement or emergency-stop behavior are provided.
MicroBlocks primitives and Linux integrationThe native adapter, UBL and Unix simulator are separate components with separate tests. This page provides no hardware acceptance evidence.

No values are saved. Sessions are limited to 256 requests and keep the last 64 method/ID records. End the session or reload to discard its fictional history. This local UI is not a robot safety control.
