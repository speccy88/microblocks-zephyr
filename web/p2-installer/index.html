Destination

Both options run a VM that can initialize or format its project storage in flash at offsets 2–8 MB. A RAM load can therefore affect saved flash projects. Back up valuable programs and projects first.

For flash boot, remove the SD card and use the documented FLASH/boot switch settings for your board.

Open P2 editor

Opening the editor does not connect a board. Its normal Connect action synchronizes the current editor project with the board.

Build and hardware scope

Native SmallVM v405, P2 extension 8. The original Edge and Eval images are compiled; installation is physically tested only on the documented Edge32 test target. Actual browser USB transfer is separate from loader-core hardware validation.
