# P4 libraries, RAM files and memory hardening

This release keeps native Zephyr SmallVM, separate USB and station build targets,
and the genuine GP browser editor. Use the P4 selector in the existing portal.
RAM files stay on the device and are erased on reset; they are not stored in
GitHub or in project serialization. Pages serves the editor, not device files.

| Feature | Available behavior | Verified boundary |
|---|---|---|
| RAM storage / Device files | Eight 8192-byte files, staged conditional writes, list/edit/read, revision/session protection | Real P4 USB: 918 requests, genuine GP create/edit/reopen, independent byte readback, resource regressions and reset volatility. Completed browser download still unverified |
| Wake Word | Explicit Okay Nabu start/stop and event hat, trusted local model | P4 fixture score/event parity and bounded microphone lifecycle; acoustic recognition unverified; listener off by default |
| JSON | Bounded parse/build and RFC6901 field CRUD, separate library | Host sanitizers and build/editor checks; physical JSON/GC acceptance not yet run |
| Clock & Timers | Monotonic timers and manually set volatile UTC/fixed-offset clock | Host fake-clock/bounds tests and editor/build checks; RTC/NTP and automatic timezone rules unavailable |
| Steps & Transitions | Explicit deterministic scans, start/stop/reset, logical steps | Host logical tests and editor/build checks; no safety certification or automatic physical actuation |
| Flash experiment | Separate portable record service + Zephyr LittleFS adapter | Native simulator/ASan/persistence tests only. Not linked, no file partition, Flash remains unavailable on P4 |
| Memory hardening | CPU-owned storage/HTTP buffers in PSRAM; isolated 64 KiB station RPC allocation pool; receive-padding bounds fix | Host/sanitizer/link audits; USB storage/PPA/NN/Whistle resource acceptance. Station pool/runtime not physically verified |
| Station Wi-Fi / self-hosting | Existing assets/HTTP/WS implementation and approved stored settings | Still blocked at C6 WifiSetConfig request284; no DHCP/board-hosted editor pass. USB editor remains usable |

Existing camera/audio/NN/PPA APIs and `p4:*` primitive indices are preserved.
JSON, clock, steps and storage use separate appended primitive sets. Flash/SD,
RTC/NTP, full JSONata and the remaining backlog are not made available by this
release. The latest installed USB artifact is documented in
[physical RAM acceptance](STORAGE_PHYSICAL.md); the station target is a separate
build with unresolved radio and runtime-memory gates.

Evidence under `evidence/` contains sanitized numerical results and hashes.
Private screenshots, recordings, model weights, credentials, device identifiers
and local machine paths are excluded from the publication set. Earlier evidence
retains its original test date and scope; simulator results are not physical proof.
CI covers source/contracts and portable host tests, not Zephyr firmware builds
or real hardware. Use the board's [START_HERE](../boards/waveshare_esp32p4_wifi6/START_HERE.md)
for the pinned build and approved-hardware-test process.
